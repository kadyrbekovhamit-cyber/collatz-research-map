What would a mathematical research project look like as a three dimensional map? ## A long search

The rule is simple: halve an even number; multiply an odd number by three and add one. The claim is that every positive start reaches one. Terras and Everett established almost everywhere descent in natural density. Bernstein and Lagarias developed exact two adic coding. These achievements explain structure, while leaving the universal question open.

## Almost all is not every

Terence Tao's major advance controls orbit minima. For any bound tending to infinity, however slowly, almost every start eventually falls below that bound, in logarithmic density. This does not establish that every start reaches one. A map must keep that distinction visible: an impressive theorem and a complete solution are different claims.

## Read the colours

Our colours describe categories, not a probability that Collatz is solved. Blue marks internally checked arguments within their stated assumptions. Cyan identifies selected published references. Amber marks open obligations. This is a navigation layout, not a mathematical distance or a formal proof graph. The data snapshot is from September sixteenth, twenty twenty six.

## Keep the corrections visible

Research history also includes corrections. The coral node records an error in an earlier route: a proposed common infimum gap could not hold. Preserving that correction matters. A useful map should make failed assumptions discoverable, alongside the arguments that survived internal checking. Independent review remains a separate step.

## The current branch has a boundary

In the public snapshot, one restricted branch reduces a first coefficient certificate to degree below four d, under explicit hypotheses. Bounds for the actual coefficients remain missing. So does coverage of arbitrary Collatz trajectories. Closing a local branch would be progress, but would not by itself establish the conjecture.
